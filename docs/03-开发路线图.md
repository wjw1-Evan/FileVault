## M0 技术验证（已完成）

- Swift 6.4 + SwiftPM 可执行目标 + AppKit 菜单栏原型（无需 Xcode 工程）
- GitRunner：git 进程封装（超时、输出捕获）
- FSEvents 流 + 事件归属第一层子文件夹验证

## M1 MVP（已完成）

| 任务 | 验收标准 | 状态 |
|---|---|---|
| GitEnvGuard 检测与安装策略 | 自动检测/安装 git，全程无终端 | ✅ |
| RootManager + ConfigStore 持久化 | 重启后根目录配置仍在 | ✅ |
| RepoManager 一级子文件夹独立仓库 | init/接管/隐藏目录跳过 | ✅ |
| WatcherEngine FSEvents 监控 | 事件正确归属第一层子文件夹 | ✅ |
| Debouncer 防抖 | 窗口内多次保存合并 1 次提交 | ✅ |
| CommitEngine 自动提交 | 变动→防抖→自动提交 | ✅ |
| 大文件保护 | 200MB 大文件被排除并记录 | ✅ |
| 暂停/恢复 | 暂停期间不提交，恢复时补全量检查 | ✅ |
| SyncManager 远程配置 + auto-push | 裸仓作远程自动推送成功 | ✅ |
| 菜单栏常驻 + 状态 | 图标/菜单状态正确 | ✅ |
| --smoke 自检 | 退出码 0 | ✅ |
