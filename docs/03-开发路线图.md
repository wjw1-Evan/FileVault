## M4 管理单元重构（v4.0，已完成）

| 任务 | 验收标准 | 状态 |
|---|---|---|
| 仓库模型改为「受管文件夹 = 一个仓库」 | 移除一级子文件夹拆仓；根级散落文件与多级子文件夹全部受保护 | ✅ |
| Watcher/Commit 收敛 | 一个文件夹一个防抖键，忽略任意层级 .git 事件 | ✅ |
| 菜单/设置/主面板/历史去掉子文件夹层级 | 每个受保护文件夹一行/一张卡；一个远程、一条历史 | ✅ |
| 整仓回滚语义（v4.0） | reset --hard 到该提交：文件夹内受版本管理的内容一起回到该版本；忽略规则排除的文件、大文件、嵌套仓库与远程仓库不受影响 | ✅ |
| 测试适配 + 新增根目录行为测试 | 全量自动化测试通过 | ✅ |
