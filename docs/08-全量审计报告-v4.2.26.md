## 2. 关键修复（数据安全优先）

1. **被忽略文件不再被静默覆盖（P1）**：`git reset --hard` / `checkout` 会覆盖「当前被 ignore、但目标版本里被跟踪」的文件，内容不在任何提交里，隐藏备份 ref 也救不回。整仓回滚、单文件恢复、目录恢复现在都会先做交集检查，命中则拒绝并列出文件。
2. **git pathspec 字面化（P1）**：恢复一个名为 `a[1].txt` 的文件曾连带改写 `a1.txt`（`*.md` 会匹配所有 markdown）。现在 `GitRunner` 统一加 `--literal-pathspecs`，保持目录前缀语义（已用临时仓库验证 add/checkout/rm/diff/log/ls-tree）。
3. **恢复/回滚与后台同步互斥（P1）**：恢复、回滚、拉取/变基/合并现在共用「远程操作 + 本地改写」两级锁；自动提交在恢复期间跳过，不再产生 index.lock 冲突或半提交。恢复期间正在 rebase 会给出可读的「请稍后再试」。
4. **首提交先绑远程（P1）**：一步添加文件夹时，远程地址在首次提交之前写入仓库，大文件在进入历史前就被排除——不会再出现「首个提交含 100MB+ 文件，之后每次推送都被 GitHub 永久拒绝」。
5. **诊断包脱敏（P1）**：`JSONEncoder` 默认把 `/` 转义成 `\/`，导致旧的脱敏逻辑完全失效、报告里带完整 `/Users/<用户名>`。现在编码使用 `.withoutEscapingSlashes` 并在 `masked()` 里先规范化转义，已加回归测试。
6. **更新包完整性 fail-closed（P2）**：GitHub API 没有 sha256 digest 时不再静默跳过校验，而是拒绝安装并提示可手动下载；解包/轮换失败给出真实原因；安装与校验移到后台线程，菜单不再冻结；回滚标记在替换 bundle 之前写入，替换失败会清除标记；回滚前校验当前版本仍是被标记的新版本（手动重装不会被误回滚）。
7. **空远程/网络恢复后自动补推（P1）**：首次推送失败留下的本地提交，之前因为周期同步把「远程缺分支」当终点而永远不上云；现在会继续走推送循环。推送循环也会避开正在进行的变基（不再出现随机「推送失败」）。
8. **菜单与主面板不再假装正常（P2）**：挂载失败的文件夹在菜单/主面板/设置显示「不可用」并给原因，可重新定位或移除；暂停的文件夹显示「已暂停」；git 自动安装期间状态行不再被 15 秒刷新覆盖。
9. **不再崩溃（P1）**：git 环境未就绪时打开「添加文件夹」、快捷添加选目录等路径会访问隐式解包的 nil `repoManager`；现在统一走 `isReady` 检查并给出可读提示（新增回归测试）。
10. **配置双实例安全（P2）**：配置缓存带文件签名，另一个实例改动后会重新读盘，不会在下次保存时把对方的文件夹列表覆盖掉；配置目录/文件权限收紧为 0700/0600。

## 3. 其它已修复问题（按模块）

- M2/M10：未装 CLT 时不再先执行 `/usr/bin/git` shim 弹 1.5GB 安装框（镜像优先）；Git 超时先终止子孙进程避免读线程泄漏；`LC_ALL/LANG` 强制为 C（父环境 locale 不再破坏错误分类）；`GIT_EDITOR/GIT_PAGER` 固定为非交互。
- M5：remote 写配置失败不再显示「已保存」；清除远程改为「应用侧停止同步」而不删用户 git 配置（其他 remote 不再偷偷继续同步）；同一失败原因只通知一次；确定性拒绝（分支保护/只读/超限）不再每次提交都通知。
- M6/M7：`git log --name-status` 改为 NUL 解析（含引号/换行/制表符的文件名不再损坏）；rename 之前的历史版本标记为不可恢复而不是恢复时报错；扫描上限判定修正（恰好扫满不再误报截断）；恢复界面区分「没有差异」与「读不到差异」；备份列表读取失败会显示错误与重试；切换文件夹不再残留上一文件夹的成功/失败文案；搜索无结果显示「没有匹配」而不是「没有被删除的文件」。
- M8/M9：设置页监听状态变化并在文件夹增减/健康度变化后刷新；保存/测试连接加互斥；`.gitignore` 读取失败不会用空内容覆盖；SSH 无密钥时显示引导；主面板历史读取失败显示错误态；菜单「打开主面板」tooltip 跟随语言。
- M14/M15：`check-large-files.sh` 对非法阈值、git 读取失败改为非零退出（不再静默放行）；`make_app.sh` 缺图标时自动生成、公证失败清理中间 zip、签名未公证时告警；README/PRIVACY 与实现对齐。

## 4. 接受的风险与未完成项（有意保留）

- **凭证按主机（host）存放**：同一 host 多账号（很少见）会互相覆盖。改为 per-path 需要 keychain 迁移方案，本次不动，避免现有用户升级后推送全部失效。
- **提交信息保持中文**（`auto: …`）：属于产品既定格式与历史数据，界面语言切换不改变已产生的提交信息。
- **历史时间线默认只加载最近 100 条**：无「加载更多」，大仓库更早版本需靠搜索/恢复窗口；属功能增强而非缺陷。
- **旧版 git 目录不自动清理**（约 40MB/次升级）；回收站式清理涉及多实例共用，本次不做。
- **发布包仅 arm64**：已修正 README 表述（Intel 需从源码构建），通用二进制属于发布流程改造。
- **UI 未做自动化**：`--smoke` 与截图渲染保留；本次新增的是核心逻辑回归测试。
