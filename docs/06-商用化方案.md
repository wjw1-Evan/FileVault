# FileVault 发布与商用方案（永久免费）

版本：v2.0 · 日期：2026-11-15 · 状态：v3.2.1 已移除试用/授权，产品永久免费

---

## 1. 结论

产品定位调整为 **永久免费**：无试用期、无激活码、无账号、无订阅、无遥测。
因此「商用化」的重心从收费链路转为 **可信分发 + 品牌 + 支持体系**。真正挡住公开发布的是三件事：

| 优先级 | 阻塞项 | 现状 | 影响 |
|---|---|---|---|
| P0 | 签名与公证 | ad-hoc 签名，Gatekeeper 首次打开需右键；无公证 | 用户装不上/不敢装 |
| P0 | 品牌名 | 「FileVault」与 macOS 磁盘加密同名 | 搜索混淆、商标风险 |
| P1 | 更新包完整性 | ~~仅校验 GitHub API 返回的 sha256（同源）~~ → **v3.3.0 已加代码签名/Team ID 校验 + 启动失败自动回退** | 供应链被篡改时无法发现 |
| P1 | 支持体系 | 有脱敏诊断包；缺公开支持入口/常见问题 | 免费用户自助成本高 |
| P2 | 国际化 | 仅中文 UI | 海外用户受限 |

> 说明：v3.2.0 曾内置 14 天试用 + Ed25519 离线授权；v3.2.1 已按「永久免费」决策**全部移除**（License.swift、授权 UI、签发脚本、授权门控）。

## 2. 免费模式

- 所有功能完整开放：多根目录、自动推送、历史回滚、诊断包。
- 不设付费墙、不做功能裁剪、不要求注册；商业环境同样免费。
- 可选的用户回报方式：GitHub Star、Issue 反馈、自愿赞助（不换取功能）。
- 免费承诺写入 EULA：本协议下的免费权利不因版本更新而收回。

## 4. 发布工程检查清单

1. swift test 全绿
2. make_app.sh <版本> → 校验 CFBundleShortVersionString
3. 若配置了 CODESIGN_IDENTITY：codesign --verify --strict 通过
4. 公证（NOTARY_PROFILE）：xcrun notarytool submit --wait → stapler staple
5. --smoke 自检通过
6. 打包 zip（ditto -c -k --keepParent），sha256 写入 Release 说明
7. 打 tag、推送、创建 Release、更新 README 下载链接
8. 灰度：先在旧版上验证一次自动更新端到端

## 5. 品牌与法务

- **改名（v4.2.31 已执行）**：新名 **Pastward**（仿 backward/afterward 构词，"驶向过去"，与「文件时光机」同构）。选择依据：原四候选经全网冲突检索全部证伪撞名（Fileback=印度文件恢复公司、SnapKeep=已上架文档扫描 App、TimeGit=活跃 GitHub 项目、Vaultkeeper=延续 vault 隐喻误导向），Pastward 无任何软件产品占用（2026-11-19 web 检索，仅学术文献的方向副词与一个无关 TikTok 账号）。已落地范围：AppBrand.swift、全部用户可见 UI 字符串与 en 表、make_app.sh CFBundleName/DisplayName/PRODUCT_NAME、README/AGENTS/PRIVACY/LICENSE。**机器标识刻意保留旧拼写**（bundle id com.filevault.FileVault、配置目录、refs/filevault/backup、模块/可执行名）——更新器 SelfUpdater 动态定位包内 .app、UpdateGuard 钉 bundle id，老用户自动升级无缝。剩余动作（需维护者执行）：注册 pastward 域名后换 AppBrand.supportEmail/websiteURL、GitHub 仓库改名（链接随 301 保持）、正式发布前做一次 USPTO/CNIPA 商标检索存档。**完整尽调矩阵、历代更新器资产匹配实证与单 zip 发布约束见 [10 品牌更名方案](10-品牌更名方案.md)。**
- **EULA**：见根目录 LICENSE（免费使用、禁止再分发/反向工程、数据归用户）。
- **隐私**：见 PRIVACY.md（无遥测、无账号、无云端中转、凭证仅钥匙串）。
- **开源合规**：当前优先调用系统/用户已有 git，未分发 git 二进制；若未来内嵌需附 GPLv2 文本与源码获取方式。

## 6. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 更新包被中间人替换 | 恶意更新 | 后续加代码签名身份校验（Team ID 绑定）+ 失败回退 |
| 免费产品支持压力 | 维护成本 | 诊断包 + FAQ + Issue 模板，减少重复沟通 |
| 改名导致用户迁移成本 | 品牌资产损失 | 提前在发布说明预告；bundle id 保持不变、配置目录兼容 |
| 公证失败 | 无法发布 | CI 固定 notarytool 流程，保留 ad-hoc 兜底包 |

## 8. 实现说明（本仓库）

| 文件 | 作用 |
|---|---|
| Sources/FileVaultCore/AppBrand.swift | 产品名、bundle id、支持邮箱、官网、隐私链接、免费声明 |
| Sources/FileVaultCore/SupportBundle.swift | 脱敏诊断报告 + zip 导出（无许可信息） |
| Sources/FileVaultApp/SettingsView.swift | 「关于与支持」卡片：诊断包、隐私政策、开源协议 |
| Sources/FileVaultCore/UpdateGuard.swift | 更新包签名校验（bundle id / Team ID 钉住）+ 启动失败回退标记 |
| scripts/make_app.sh | 支持 Developer ID 签名 + notarytool 公证 + staple |
| Tests/FileVaultTests/SupportBundleTests.swift | 诊断脱敏/免费声明/无凭证泄漏/导出 5 项测试 |
| Tests/FileVaultTests/UpdateGuardTests.swift | 回退标记生命周期/Team ID 钉住矩阵/签名与篡改检测 7 项测试 |

发布命令（本地 ad-hoc）：

    ./scripts/make_app.sh 3.2.1

发布命令（对外分发，需 Apple Developer ID）：

    CODESIGN_IDENTITY="Developer ID Application: 你的名字 (TEAMID)" NOTARY_PROFILE=fv-notary ./scripts/make_app.sh 3.2.1
